# Working examples

The Projects vertical slice is the primary reusable CRUD example: schema → migration → owner/organization authorization → Zod → API → React Hook Form → UI → tests.

Other executable examples: development `/gallery` (Radix controls, fields, tables, chart with explicitly illustrative data), optional `/dashboard/ai` (chat/structured/text/read-only tools), billing and private file routes. These use the actual modules rather than duplicate template implementations.

Start from docs/ai/recipes.md for minimal extension steps. Never substitute static success responses for provider calls.
